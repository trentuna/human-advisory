# Human Advisory — VISION

**Status:** Living document — updated when vision meaningfully shifts

## One-line vision

> Make AI-generated code visibly, undeniably, permanently labeled — so every person who reads it reads it differently.

## The why

In 1996 the music industry put a sticker on records so you knew what you were buying. In 2026 AI-generated code floods the web with no label at all. Human Advisory is that sticker, reissued: same proportions, same monochrome bands, a different confession. The badge isn't a legal requirement — it's a cultural signal. You see it, you read the code differently. That's the entire point.

## Core principles

1. **One link, one div** — No JavaScript, no build step, no framework. Add a CSS link and an HTML div. Done.
2. **Self-contained** — League Gothic is base64-embedded in the CSS. Works offline, in airgapped docs, behind firewalls.
3. **Cultural object, not UI component** — The badge is a statement, a flag, an admission. The design carries the weight of the original RIAA sticker.
4. **Own what you built** — The badge is affirmative disclosure. You're not hiding; you're being honest.

## Non-goals

- Police or audit AI-generated code
- Provide attribution or provenance tracking
- Replace licensing or legal disclaimers
- Become a mandatory standard or regulation tool

## Decision framework

1. Does this make AI disclosure easier or harder to adopt?
2. Does it preserve the badge's visual weight and cultural resonance?
3. Is it still one CSS link and one div when done?

## Measures

npm install, cdn link, or self-host — each path works in under 60 seconds. The badge is recognizable at a glance at any size (xs through xl). At least one major open-source project outside Trentuna uses it on their README or site.
